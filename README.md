# YouTube Comment Moderation Agent

A web application that helps YouTube channel owners review comments,
moderate harmful content, and generate AI-assisted replies.

## Features
- Google OAuth login
- YouTube channel and video selection
- Comment retrieval through YouTube Data API
- Comment moderation actions
- AI-assisted reply generation
- Multi-user support

## Tech Stack
- Python
- Flask
- Google OAuth 2.0
- YouTube Data API v3
- AG2 / multi-agent workflow

## Run Locally
1. Clone this repository.
2. Create a virtual environment.
3. Install dependencies with `pip install -r requirements.txt`.
4. Create the required environment variables.
5. Run the Flask application.

## Security Note
Never commit API keys, OAuth client secrets, tokens, or user databases.
